# Filament Page Header

Reusable, schema-based page headers for Filament 5.

## Project status

Initial repository setup. The plugin, demo application, and test suite have not been implemented yet. No installable release is available.

## Planned scope

Configurable titles, subtitles, badges, avatars, metadata, and actions using Filament schemas. Optional sticky and compact header modes, responsive layouts, and per-panel and per-page configuration.

The package will be independent of any consuming application. Local development will support Composer path repositories with symlinks.
