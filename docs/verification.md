## What is covered

- Panel/page opt-in, native and custom-header fallback, shared resource schemas, overrides and configuration isolation.
- Create/List without a persisted record, View/Edit with a record, native enum badges, escaping and explicit trusted HTML.
- Native render hooks, save form targets, confirmations, denied action visibility and retention of unsaved inputs.
- Ten header compositions at widths 360, 390, 768, 1024 and 1440 CSS pixels.
- Normal, sticky and compact modes; min-width overrides; automatic/explicit/missing-topbar offsets.
- Padded nested scrolling, repeated threshold crossings, short viewport fallback and idempotent controller disposal.
- Focus and anchor visibility, topbar focus not moving the page, orientation changes, dark mode and reduced motion.
- Native and schema actions, modal stacking, repeated SPA navigation and no requests generated by the tested scroll/resize paths.

Browser screenshots, failure traces when applicable and the HTML report are available in the `browser-report` artifact on the run. A generated screenshot is evidence of rendering, not a claim of a human visual review.

## Issues found and corrected during verification

1. Native Filament modals position their visible window inside a wrapper with no useful height. Browser assertions now verify the actual window, the accessible dialog state and a working confirmation button rather than the wrapper's bounding box.
2. Focusing topbar controls incorrectly triggered the header's content-reveal scroll correction. The correction now applies only to the current page and excludes dialogs and other header instances.
3. Nested sticky boundaries did not include the scrollport's top padding. The controller and regression test now cover the inner padded edge and border.
4. Invalid resource schema mappings and missing panel registration now produce explicit exceptions rather than ambiguous runtime failures.

## Limits and remaining review

- Chromium viewport changes approximate mobile layouts. Physical iOS/Android keyboards, Safari, Firefox, assistive technologies and real-device zoom have not been verified in this run.
- An independent human design/accessibility review is still appropriate before a stable public release. Do not describe the automated checks as a complete accessibility certification.
- Laravel Pint is available through `composer format` and `composer format:check`, but no passing Pint or PHPStan result is claimed in this record. The recorded CI checks are the ones listed above.
- The local Composer path workflow is documented but has not been executed inside the user's Pressiu Docker environment. Pressiu integration belongs to a separate card and remains unmodified by this package work.
